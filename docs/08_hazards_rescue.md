# 08 危険（転倒・滑落・落雷）・機器・救助

## 1. 転倒・滑落（`hazards/slip.ts`）

### 1.1 地形クラス

| クラス | 判定 |
|---|---|
| `T1` | 登山道 class T1 |
| `T2` | 登山道 class T2 |
| `EXPOSED` | 登山道 class T3、または hazard `chain` 区間 |
| `OFF` | 道外で傾斜 ≤ 30° |
| `OFF_STEEP` | 道外で傾斜 30〜45° |
| `CLIFF` | `cliff` セル、または `waterfall` 半径内（道外） |

### 1.2 発生率

10 m 移動するごとに `hazard` ストリームで判定。

```
base100 = { T1: 0.0015, T2: 0.004, EXPOSED: 0.010, OFF: 0.012, OFF_STEEP: 0.04, CLIFF: 0.35 }
p10 = base100/10
    * (地面 wet>0.5 ? 1.6 : 1)
    * (icy ? (crampons ? 1.3 : 4.0) : snowCm > 5 && slope > 20° ? (crampons ? 1.1 : 2.5) : 1)
    * (isDark ? (headlampOn ? 1.5 : 4.0) : 1)
    * (1 + fatigue/80)
    * (1 + 2*(1 - M))
    * (1 + (1 - J))
    * (hurry ? 1.3 : 1)
    * (trekkingPoles && class != CLIFF ? 0.8 : 1)
    * (下り ? 1.3 : 1)
```

### 1.2b 靴（DECISIONS 2026-11-21）

`gear.footwear` で転倒の確率に倍率を掛ける（`tuning.slip.footwear`）。いつも（base）・下り（down）・濡れ（wet）・雪や氷でアイゼンなし（snow）。登山靴 1、スニーカー 1.6・下り ×1.5・濡れ ×1.3・雪 ×2、トレランシューズ 1.15・1.15・1.2・1.4、冬用の登山靴 0.95・0.95・1・0.8。高地脳浮腫では ×2.5（ふらつき）。

### 1.3 結果（重症度表）

| クラス | 何もなし（立て直し） | bruise | sprain | legFracture | headInjury | severeTrauma | 即死 |
|---|---|---|---|---|---|---|---|
| T1 | 0.70 | 0.24 | 0.05 | 0.01 | 0 | 0 | 0 |
| T2 | 0.55 | 0.30 | 0.10 | 0.04 | 0.01 | 0 | 0 |
| EXPOSED | 0.30 | 0.25 | 0.15 | 0.12 | 0.08 | 0.05 | 0.05 |
| OFF | 0.55 | 0.30 | 0.10 | 0.04 | 0.01 | 0 | 0 |
| OFF_STEEP | 0.30 | 0.30 | 0.15 | 0.13 | 0.06 | 0.04 | 0.02 |
| CLIFF | 0.05 | 0.10 | 0.10 | 0.25 | 0.15 | 0.15 | 0.20 |

- 既に負傷している場合は重い方を残す。
- `EXPOSED` 以上で負傷したら、斜面下方へ 10〜40 m 移動（落ちた）し道外になる（`hazard` ストリームで距離）。CLIFF は滝・崖の下へ。
- イベント `FALL { severity, x, z }` を出し、汎用分岐点 `injured` の条件になる。

## 2. 落雷（`hazards/lightning.ts`）

```
exposureL = 山頂ノード 50m 以内: 1.0 / 稜線（tpi > 60 かつ ALPINE/ROCK）: 0.6 / 開けた斜面: 0.2
           / 森林内: 0.06（ただし「木のそばで雨宿り」状態なら側撃 0.5）/ 小屋内: 0 / 沢・窪地: 0.04
postureF = 雷しゃがみ姿勢（lightningPosture）0.5 / 移動中 1.0
pStrikePerMin = 0.004 * thunderLocal^2 * exposureL * postureF
```

- 金属の有無は確率に**影響しない**（俗説）。シナリオで「金属を外す」選択肢を出す場合も効果は時間の浪費のみ。
- 被雷: 死亡 0.3、意識喪失＋熱傷（`headInjury` 相当＋ M 0.5）0.7。同行者が 5 m 以内にいれば 0.3 の確率で地面電流による `bruise` と一時的な M 0.3（30 分）。
- 保護範囲（高い物体の頂点を 45° 以上で見上げ、物体から 4 m 以上離れる）: マップの `hazards` に `protectionZone` を置けば `exposureL × 0.3`（初版は任意）。

## 3. スクリプト危険

- 落石: シナリオイベントの効果 `injure` / `rockfall`（hazard `rockfallZone` 内で発生確率を指定）。
- 渡渉の増水: エッジに `fordAt: s` がある場合、局地降水が 10 mm/h 超の積算 30 mm 超で通行不能フラグ（初版は任意）。

## 4. 機器（`devices.ts`）

### 4.1 スマートフォン

| 項目 | 値 |
|---|---|
| 電池消費（%/h） | 待機 2、GPS 軌跡記録 6、通話 20（1 回 10 分）、位置確認 1 回 2 |
| 寒さ | `phoneTempC = 局地気温 + 15`（ポケット内）。< 0℃ で残量表示の 20% を下回ると突然 0% になる（`batteryCliff`） |
| 電波 | `radio[cell]`（docs/04 §7） |
| 衛星 SOS | `satelliteSos: true` の端末は `skyView ≥ 0.5` で送信可能（送信に 5〜15 分、電池 −5%） |

`habits.gpsCheckEveryMin`: 指定した間隔で位置を確認（電池消費あり）。null なら確認しない。

### 4.2 ヘッドランプ

`headlamp: { has, batteryH, inPack }`。点灯中に `batteryH` を消費。0 で消灯。予備電池 `spareBatteryH`。

## 5. 救助（`rescue/rescue.ts`）

### 5.1 通報経路

| 経路 | 条件 | 位置精度 |
|---|---|---|
| 電話 | `radio ≥ 0.3` で 1 回 10 分。`0.15〜0.3` は成功率 0.5/回 | GPS アプリあり: ±50 m、なし: 本人の説明 = `routeBelief` の位置（道迷い中は大きくずれる）±500 m |
| 衛星 SOS | §4.1 | ±50 m |
| 未帰還通報 | シナリオ `plan.reportIfNotBackBy`（例 "D0 21:00"）を過ぎ、下山報告がない | 計画ルート全体 |
| 他の登山者の通報 | スクリプトイベントのみ | 指定 |

通報成功でイベント `RESCUE_CALLED`、`world.rescue.status = "dispatched"`。

### 5.2 出動

**ヘリ**（`heli`）

```
飛行可能 = 明るい（日の出+30分〜日の入り−60分）
        && 目的地点の視程 > 1500 && 目的地点 < 雲底 − 100 && 局地風 < 15 && thunderLocal < 0.2
出動準備 45〜90 分（rescue ストリーム）。準備完了時に飛行不可なら 60 分ごとに再判定。
到着後: 位置精度 ±50m なら 15 分で吊り上げ。精度が悪い場合は上空捜索（1 時間あたり発見確率 0.6、
        森林内は 0.25、登山者がライト/ツェルト等で合図できるなら ×1.5）。
```

**地上隊**（`ground`）

```
招集 90〜180 分（夜間 +60）。登山口から登山道 2.5 km/h、道外 0.8 km/h で A*。
位置精度が悪い場合: 推定範囲の中心へ向かい、範囲内で捜索（1 時間あたり発見確率 0.35 × 視界係数、
       登山者が声・笛・ライトで応答可能（conscious）なら ×1.6）。
```

両方を並行で進め、先に接触した方で `RESCUED`。接触時に生存していれば:
- core ≥ 32 かつ 重度外傷なし → `RESCUED`
- それ以外 → `RESCUED_CRITICAL`

救助隊到着後の熱環境は営業小屋相当（ただし core の回復は +0.5℃/h 上限）として結末判定まで進めない（接触時点で結末確定）。

### 5.3 未帰還通報からの捜索

位置不明の捜索は、計画ルートから 300 m 以内を優先し、そこで見つからなければ 1 時間ごとに捜索範囲を 300 m 広げる。
`DESCENDING_DRAINAGE` で沢深くに入った登山者は見つかりにくい（森林・沢セルの発見確率 ×0.5）。
これで「計画書と下山連絡の大切さ」「沢を下ると見つけてもらいにくい」が結果に出る。
