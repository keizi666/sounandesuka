# 20. みんなの遭難記録（公開の記録と感想）

ユーザーがシナリオを遊んだ結果と推移を、ニックネームと一緒に公開し、ほかの人の記録を見られるようにする機能。
本アプリで唯一サーバー（自前の小さな API）を使う。CLAUDE.md 鉄則 8 の例外（DECISIONS.md 2026-11-20）。

## 1. 画面

| 場所 | 内容 | ファイル |
|---|---|---|
| トップ（シナリオ一覧） | 見出しの帯の下・「シナリオを選ぶ」の上に、横長のバナー（水色・角丸・白い文字）。最近載せた人の顔と件数 | `src/ui/community/banner.ts` |
| 結果の画面 | 「みんなの遭難記録に載せる」欄。プロフィール・感想（200 字まで）・「記録を載せる」。載せたら「載せた記録を見る」 | `src/ui/community/postCard.ts` |
| 一覧（`community`） | シナリオで絞り込み、結末の割合の帯と結末での絞り込み、カード（人・シナリオ・結末・時間・最低体温・距離・選択の数・感想）、もっと見る | `src/ui/community/communityScreen.ts` |
| 詳細（`communityRun`） | 人・結末・数字、感想（通報／自分のなら消す）、分岐での選択、地図の軌跡（拡大縮小）、体温と天気のグラフ、メンバーの状態の推移 | `src/ui/community/communityDetail.ts` |
| プロフィール | ニックネーム（12 字）・性別・年代（どちらも「答えない」可）・アイコン（似顔絵 64 種・絵文字 67 種・アップロードした画像）・枠の色、引き継ぎコード、端末から外す、すべて消す | `src/ui/community/profileDialog.ts` |

- 載せられるのは、公開しているシナリオ（`public/scenarios/index.json` にあるもの）の結果だけ。エディターやファイルから開いたシナリオは載せない。
- 詳細のグラフと地図は振り返りと同じ部品（`drawTimeline`・`memberCharts`・`drawMap2d`・`zoomableMap`）。地形データを公開していないシナリオ（実在の山）は、軌跡だけを方眼の上に描く（`trackOnly.ts`）。
- 結末・振り返りと同じ注記（架空のモデル、実在の山、史実の注記）を出す。

## 2. 本人の識別

- パスワードもメールアドレスも使わない。プロフィールを作ると、サーバーが 24 文字のランダムなトークン（`0-9A-Z` から I L O U を除いた 32 種）を返し、端末の localStorage に置く。
- API には見出し `X-Sounan-Token` で送る。サーバーは塩を混ぜたハッシュだけを持つ。
- トークンは「引き継ぎコード」として見せる（6 文字ずつハイフン区切り）。別の端末で入れると同じプロフィールになる。
- 「この端末から外す」は端末のトークンを消すだけ。「すべて消す」はサーバーのプロフィールと記録・感想をすべて消す。

## 2.1 アイコン

プロフィールの `portrait` に、次のどれかを入れる（`src/net/rules.ts` の `parseIcon`）。

| 種類 | 値 | 出し方 |
|---|---|---|
| 似顔絵 | `mid_m:3` | `public/portraits` のイラスト（`src/ui/avatar.ts`） |
| 絵文字 | `emoji:🏔️` | OS の絵文字をそのまま（画像は同梱しない）。決まった 67 種（`EMOJIS`。`lib.php` にも同じ並び）から選ぶ。端末で見た目が少し違う |
| 画像 | `img:<10 桁の 16 進>` | サーバーに置いた画像。値はその版（中身のハッシュ）で、URL `api/index.php?a=avatar&u=<利用者>&v=<版>` に入るので長く覚えさせてよい |

画像の流れ:

1. 端末で PNG・JPEG・WebP・GIF（最初のコマ）を選ぶ（20 MB まで）。EXIF の向きを当てて読む。
2. 丸い枠に合わせて、ドラッグで位置、つまみ・ホイールで大きさを決める（`avatarCrop.ts`）。
3. 256 × 256 の WebP（作れない端末は JPEG）に縮める。200 KB を超えたら質を下げる。
4. プロフィールを保存したあとに `avatar` で送る。サーバーは形（PNG・JPEG・WebP、32〜1024 px）を確かめ、GD で 256 px に描き直して（EXIF などの付帯情報はここで落ちる）`dataDir/avatars/<利用者>.webp`（GD に WebP がなければ PNG）に置く。1 時間に 10 回まで。
5. 画像をやめる（ほかの種類を選んで保存する）・すべて消す・管理ページの「アイコン画像を消す」で、ファイルも消す。

画像はすぐ公開する。投稿の通報（感想・アイコンを含む）で隠れ、管理ページでは利用者の画像が見えて、画像だけを消せる（似顔絵に戻る）。

## 3. API

`<base>/api/index.php?a=<操作>`。応答は JSON。誤りは `{ "error": "<code>" }`（code は `ja.ts` の `community.errors`）。
POST は `Content-Type: application/json` に限る（よそのサイトのフォームからは送れない）。本文は 800 KB まで。

| 操作 | メソッド | トークン | 内容 |
|---|---|---|---|
| `list` | GET | 任意 | `scenario`・`ending`・`user`・`offset`・`limit`（50 まで）。`{ items, total, counts, scenarios }` |
| `run` | GET | 任意 | `id`。記録つきの 1 件。隠したものは本人だけ |
| `me` | GET | 要 | 自分のプロフィール（引き継ぎコードの確かめ） |
| `register` | POST | − | プロフィールを作る。`{ user, token }` |
| `profile` | POST | 要 | プロフィールを直す |
| `post` | POST | 要 | `{ summary, record, comment }` を載せる |
| `delete` | POST | 要 | 自分の記録を消す |
| `forget` | POST | 要 | 自分のプロフィールと記録をすべて消す |
| `report` | POST | − | 通報（同じ IP から 1 件に 1 回） |
| `avatar` | POST | 要 | `{ image }`（base64）でアイコンの画像を置く。返るプロフィールのアイコンは `img:<版>` |
| `avatar` | GET | − | `u`・`v`。アイコンの画像（`image/webp` か `image/png`） |

型は `src/net/communityTypes.ts`。

### 3.1 要約（summary）

シナリオ ID・結末・行動時間・距離・最低体温・人数・亡くなった人の数・分岐での選択（40 件まで）・条件を変えたか・アプリの版。
シナリオの題名はサーバーが `scenarios/index.json` から取る（送られた題名は使わない）。

### 3.2 記録（record）

`RunRecord` から振り返りのグラフと地図に要るものだけを残し（出来事は転落・死亡・救助・道迷いの自覚・落雷・心停止・通報・小屋・ビバーク・下山だけ）、数値を丸めて、gzip（`CompressionStream`）＋ base64 にする（`src/net/recordPack.ts`）。
600 KB まで。ふつうは 7〜30 KB。サーバーは中身を解かずに、gzip の先頭であることだけを確かめて持つ。

## 4. 投稿の決まり

値は `src/net/rules.ts` と `server/api/lib.php` の両方に書く（変えるときは両方）。

- ニックネーム 12 字まで（改行不可）、感想 200 字・6 行まで、空の感想は可。
- 制御文字・書字方向を変える文字は不可。URL・ドメインらしいものは不可。
- NG ワード: 既定の短い一覧（`rules.ts`・`lib.php`）に、サーバーの `dataDir/ngwords.txt`（1 行 1 語、`#` で始まる行は注記。git に入れない）を足す。全角・半角と大文字・小文字をそろえ、空白を詰めてから比べる。
- 回数の制限（IP アドレスは塩を混ぜたハッシュで数える）: 記録を載せるのは 1 分に 1 件・1 日 30 件、プロフィールを作るのは 1 時間に 5 件、直すのは 1 時間に 20 回、通報は 1 日 30 件。
- 即時公開。通報が 3 件（別々の IP）たまると自動で隠す。管理者が戻す・消す。

## 5. サーバー（さくらのレンタルサーバー）

- PHP 8 ＋ SQLite（PDO）。外部のライブラリは使わない。ファイルは `server/api/`（`index.php`・`lib.php`・`admin.php`・`.htaccess`）。
- `npm run deploy` が `server/api` を `dist/api` に写し、`deploy.config.json` の `api` から `config.local.php`（データの置き場所・塩・管理トークンのハッシュ）を作って一緒に上げる。塩と管理トークンがなければ作って `deploy.config.json` に書き足す。`deploy.config.json` も `config.local.php` も git に入れない。
- データの置き場所 `api.dataDir` は公開フォルダーの外がよい（例 `/home/<user>/sounandesuka-data`）。省略すると `api/data`（`.htaccess` で読めなくする）。初めて呼ばれたときにフォルダーと表を作る。
- `.htaccess` で、外から開けるのは `index.php` と `admin.php` だけにする。
- 管理ページ `<base>/api/admin.php`: 管理トークンを入れると、新しい 200 件（または通報あり・隠したもの）が見え、隠す・戻す・消す・利用者ごと消すができる。トークンの誤りは 1 時間に 10 回まで。
- IP アドレスはそのまま残さない（塩を混ぜたハッシュで、回数の制限と通報の重なりにだけ使う）。サーバーのアクセスログは別。

## 6. 開発

- 手元には PHP がないので、`npm run dev` のときだけ Vite のプラグイン（`tools/devApi.ts`）が同じ API を真似る。データは `.scratch/dev-community.json`。
- 決まりは `rules.ts` を共有。連投の制限だけ緩い（5 秒）。
- テスト: `tests/community.test.ts`（決まり・引き継ぎコード・記録の圧縮と復元）。PHP は手元で動かしていないので、公開前にサーバーで一度通しで確かめる（プロフィール作成 → 投稿 → 一覧 → 詳細 → 通報 → 管理ページ）。
