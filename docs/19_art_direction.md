# 19. 画づくりの方針（アートバイブル）

2026-11-19 のユーザー指示による。**この文書は docs/10（レンダリング）より優先する。** 承認後、docs/10 の食い違う箇所を書き換える。

目標: 「図形を組み合わせた見た目」から、可愛さと写実性が両立したスタイライズド表現へ。特定の作品のキャラクターやアセットは模倣せず、画づくりの手法と品質の水準を目標にする。

## 1. 現状の調査（フェーズ 0。コードは変更していない）

| 項目 | 現状（`src/view/`） | 目標との差 |
|---|---|---|
| ライト | 太陽の DirectionalLight 1 灯（時刻で方位・高度・色が変わる。夜は月として使い回す）＋ HemisphereLight ＋ 環境マップ（three 同梱の RoomEnvironment）。`sceneView.ts` | 構成はある。太陽高度は時刻どおりなので、朝夕以外は影が短い。比較用の固定視点では時刻を固定する必要がある |
| 影 | シャドウマップ 1 枚（高 2048 / 中 1024 / 低 なし）で地図全体を覆う。three r187 では PCFSoft が廃止され PCF に落ちる。0.4 秒ごとに更新 | 1 枚で 4〜12 km を覆うので 1 画素が 2〜6 m。木 1 本の影がぼやける。カスケードか、カメラ周辺に絞った影が要る |
| 環境遮蔽 | なし（樹木の頂点色で「内側・下側を暗く」しているだけ） | 木の根元・林内・道の縁の暗さがない |
| 霧・空気遠近 | 雲の中だけ灰白色に霞む（標高フォグ）。距離フォグなし | 遠景が青く霞まない。平板に見える主因の一つ |
| 空 | 天頂〜地平の階調、太陽の光芒、星（`sky.ts`） | 土台はある。雲は点スプライト |
| トーン・後処理 | ACES、sRGB。EffectComposer: にじみ → 上下ぼかし（常時オン）・周辺減光・彩度（`post.ts`） | ティルトシフトの切替がない。**ユーザーの Chrome では「にじみ」だけ真っ黒になり、自動で切っている（原因未特定。WebXR 拡張機能を疑っている）**。SSAO も同じ問題に当たる可能性がある |
| マテリアル | すべて MeshStandardMaterial（PBR）を onBeforeCompile で拡張（雪・濡れ・夜・霧）。トゥーンなし、リムなし | 共通のトゥーンシェーダーに置き換える |
| 樹木 | `treeShapes.ts`: 広葉樹 = 幹＋でこぼこの二十面体 3〜7 個、針葉樹 = 幹＋ぎざぎざの円錐の段 4〜8。変種 2〜3、InstancedMesh、近景／遠景は全体で一括切替。風の揺れあり | 指摘どおりプリミティブ感が強い。葉の板・放射法線・樹種・インポスターなし |
| 配置 | `vegetation.ts`: 植生クラスのセルごとに一様乱数で散布。岩は岩場・崖・高山帯に散布 | 群生・疎密・林縁・道沿い／沢沿いの違いなし。林床なし |
| 地形 | `terrainMesh.ts`: 高さマップの格子（セル 16〜24 m）。頂点色 = 植生クラスの色。シェーダーで 2 スケールのノイズ、急斜面の岩肌、法線の揺らし | 土・落ち葉・草の区別がほぼない。メッシュの微細な起伏なし。トライプラナーなし |
| 登山道 | `trails.ts`: 地表から 1.2 m 浮かせた半透明の帯（MeshBasicMaterial。照明を受けない） | 指摘どおり浮いた白い帯 |
| 沢 | 植生クラス STREAM の頂点色（青灰色）だけ。水面なし | 水の表現が存在しない |
| 人形 | `figureModel.ts`: カプセル・球・回転体など約 80 メッシュを関節の階層に付けた剛体パーツ。7.3 頭身。`figureMotion.ts`: 関節角を手続きで与える（歩行・座る・震える等 10 姿勢） | 連続したメッシュ・スキニング・IK・輪郭線なし。頭身が高く可愛さがない |
| 尺度 | 人形は 25 倍、樹木は 2.2 倍に拡大（箱庭全体を見下ろしても見えるように） | 人形が木と同じ高さになる。近景の画づくりではこの比率が不自然さの原因になる（§6 で相談） |
| 性能 | 未計測。画質は GPU 名から自動判定（低 / 中 / 高） | 計測の仕組みがない |

## 2. 舞台設定（画面から伝えること）

**本州中部の亜高山帯（標高 1,500〜2,600 m）、10 月中旬の朝。** 山麓はブナ・ミズナラ・カエデの紅葉の盛り、中腹はオオシラビソ・コメツガの濃い緑にダケカンバの黄色が混じり、森林限界の上はハイマツと草紅葉、稜線は灰色の岩。空気は乾いて澄み、遠くは青く霞む。

## 3. 色パレット（12 色）

| 役割 | HEX | 使いどころ |
|---|---|---|
| 空（天頂） | `#3F7FD6` | 澄んだ秋空 |
| 空（地平）・遠景の霞 | `#BFD9EE` | 距離フォグの色もこれ |
| 日なたの光 | `#FFF1D6` | 太陽の色（やや暖かい） |
| 影の色 | `#4A4F8C` | 影側に掛ける青紫。黒くしない |
| 針葉樹 | `#2F5D45` | オオシラビソ・コメツガ |
| ハイマツ・苔 | `#5E8A4A` | 明るい緑 |
| 黄葉 | `#E8B92F` | ブナ・ダケカンバ・カラマツ |
| 橙葉 | `#DB7A2B` | ミズナラ・ブナの遅い葉 |
| 紅葉 | `#C2402E` | カエデ類 |
| 草紅葉・落ち葉 | `#B58A4A` | 高山帯の草地、林床 |
| 土・登山道 | `#8A6A4C` | 踏み固めた土 |
| 岩 | `#8E8C88` | 稜線・沢の岩（影側は影の色へ寄る） |

補助: 幹（濃）`#4B3A2C`、ダケカンバの幹 `#E9E3D6`、水 `#3E7C8C`、キャラクターの差し色は彩度の高い赤・青・黄（背景にない色）。

## 4. 陰影

- **3 段**（日なた・半影・影）。境界は smoothstep で柔らかくつなぐ（幅は段の 15〜25%）。硬いセル塗りにはしない。
- 影側は明度を落とすだけでなく、**色相を青紫（`#4A4F8C`）へ寄せる**。最も暗い部分でも明度 25% を下回らない。
- 逆光側に**リムライト**（空の地平色）。環境は法線ベースの上下グラデーション（上 = 空色、下 = 地面の照り返し）。
- 鏡面反射は水と濡れた面だけ。それ以外はつや消し。
- 色のばらつきは「個体ごとの一様乱数」ではなく、**ワールド座標の低周波ノイズ**で色相 ±6°・明度 ±10% をゆるやかに変える。

## 5. 輪郭線

- **キャラクターだけ**に入れる。背面法線法、太さは画面上でおよそ 1.5〜2 px、色は黒ではなく濃紺茶 `#2A2433`。
- 樹木・地形・建物には入れない（陰影と霞で分離する）。

## 6. キャラクター

- **4.5 頭身**。頭・手・登山靴をやや大きく、胴は短め、脚は太め。顔は単純（目と眉、口は小さく）。
- 1 つの連続した滑らかなメッシュ＋スキニング。装備（ザック・ストック・帽子・レインウェア）は形として作る。
- 動き: 歩行・急登・下り・休憩・疲労・震え。足は IK で斜面に接地。
- **相談 1（作り方）**: (a) SDF＋Marching Cubes で手続き生成、(b) CC0 の glTF を読み込む。→ 推奨と理由は報告本文。
- **相談 2（尺度）**: いまは人形 25 倍・樹木 2.2 倍。可愛い 4.5 頭身にしたうえで、樹木を 4〜5 倍に上げて「木のほうが人より高い」比率に寄せることを提案する（本数は減らして密度感を保つ）。

## 7. 樹種ごとのシルエット

| 樹種 | 分布 | シルエット | 色 |
|---|---|---|---|
| ブナ | 山麓〜中腹、緩い斜面 | 幹はまっすぐ太く灰色。樹冠は横に広い卵形で、葉の塊が 3〜4 層 | 黄〜橙 |
| ミズナラ | 山麓、尾根 | 幹がやや曲がり、枝が横に張る。樹冠はいびつで低い | 橙〜茶 |
| カエデ類 | 沢沿い、林縁 | 細い幹が株立ち。小さく丸い樹冠が段になる。背は低い | 赤 |
| ダケカンバ | 森林限界の近く | **白い幹**が斜めに曲がる。樹冠はまばらで透ける | 明るい黄 |
| オオシラビソ | 中腹〜森林限界 | 細い円錐だが輪郭は不規則。枝先が垂れ、頂は尖る。下枝が長い | 濃緑（青み） |
| コメツガ | 中腹の尾根・岩場 | 樹頂が傾き、枝が不ぞろいに横へ伸びる。やや丸い | 濃緑 |
| カラマツ | 山麓の日なた、道沿い | 細く高い。枝は疎らで水平、葉は軽い房 | 金色 |
| ハイマツ | 森林限界の上 | 地をはう低いうねり。ひとかたまりで斜面を覆う | 明るい緑 |

- 樹冠は葉の板（アルファテスト）を樹冠の体積にばらまき、法線を樹冠中心からの放射方向に書き換える。葉のテクスチャはコードで生成する。
- 各樹種 2 変種、計 8 種以上。遠景はインポスター。
- 配置はポアソンディスク＋群生。林縁・疎林・密林の差をつけ、道沿いは明るい疎林、沢沿いはカエデと苔の岩。

## 8. 確認の仕組み

- 固定視点 3 つ（時刻も固定: 10 月 17 日 9:30、太陽高度 約 35°）
  1. **全景**: 箱庭全体を南東の上空から
  2. **林内**: 登山道を歩く登山者を斜め後ろから（人物が画面の高さの 1/4）
  3. **稜線と沢**: 森林限界の上から、沢と稜線を見下ろす
- 各フェーズの前後でスクリーンショットを自動取得して並べ、プリミティブ感の残る箇所を書き出す。
- FPS を同じ視点で計測する。目標: ミドルレンジのノート PC で 60 fps、スマホで 30 fps。
