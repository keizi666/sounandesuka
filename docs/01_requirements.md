# 01 要件

## 1. 機能要件

### シナリオと進行
- **FR-01** シナリオ一覧からシナリオを選べる。カードに題名・季節・テーマ（低体温症／道迷い／落雷など）・難易度・所要実時間の目安を表示する。
- **FR-02** 開始前に **ブリーフィング** を表示する: 計画ルート（2D 地図）、パーティと装備、出発前に登山者が見た天気予報、計画のコースタイム。
- **FR-03** シミュレーションはゲーム内時刻で進む。速度は 一時停止 / ×1（ゲーム1分=実1秒）/ ×4 / ×15 / ×60（夜間の待機など用）。
- **FR-04** 分岐点の発火時は既定で自動一時停止し、選択肢モーダルを出す。
- **FR-05** 「判断時間制限モード」（設定）では、分岐点でも ×1 で時間が流れ続け、制限時間（シナリオ指定、既定 30 実秒）を過ぎると登山者の自律バイアスで選ばれる。
- **FR-06** 「観察のみモード」では全分岐点を自律バイアスで自動決定し、ユーザーは見るだけ。
- **FR-07** 重要イベント（雨の降り始め、日没、道迷い、転倒、体温の段階変化、救助要請など）で自動一時停止するかを設定で切り替えられる（既定: 分岐点のみ停止）。
- **FR-08** 全登山者が終端状態（下山完了・小屋で安全確保・救助・死亡）になるか、シナリオの制限時間に達したら結末を判定し結末画面を出す。

### 観察
- **FR-10** 3D ジオラマを回転・ズーム・パンできる（マウス／タッチ）。
- **FR-11** カメラモード: 俯瞰（自由）／追従（選択中の登山者を追う）／登山者視点（局地の視程どおりの霧で前方を見る）。
- **FR-12** 登山者パネル: 体温、エネルギー、水分、疲労、濡れ、不安、判断力・運動能力（神の視点時のみ数値）、状態、装備アイコン、スマホ電池・電波。
- **FR-13** 気象パネル（登山者の位置の局地気象）: 気温、体感温度、風速、降水（種類つき）、視程、雲底高度、雷の危険度。
- **FR-14** 思考の吹き出し: 登山者の内心をテンプレートから生成して表示（例「まだ大丈夫、小屋まであと少し」）。
- **FR-15** イベントログ: 時刻つきで行動・気象変化・身体の変化を記録表示。
- **FR-16** オーバーレイ切替: 登山道、計画ルート、実際の軌跡、気温分布、風、雲層、電波圏、危険箇所。
- **FR-17** 情報モード切替（神の視点／登山者の視点）。登山者の視点では、道迷いに気づくまで「計画ルート上にいるつもりの位置」を表示し、真の位置・気象の先読み・数値は隠す。

### 分岐点
- **FR-20** 分岐点モーダルは「状況の文章」「登山者が把握していること」「選択肢 2〜4 個（各選択肢の補足）」を表示する。
- **FR-21** 利用条件を満たさない選択肢（例: 電波なしの救助要請）は表示しないか、理由つきで無効表示する（シナリオで指定）。
- **FR-22** 選んだ内容と時刻を記録し、振り返りで使う。

### 振り返り
- **FR-30** 結末画面: 結末名、要約文、所要時間、最低体温、主な分岐の選択、注記。
- **FR-31** 振り返り画面: 時系列グラフ（体温・エネルギー・気温・風・降水）に分岐点と主要イベントのマーカー、2D 地図上の軌跡。
- **FR-32** What-if: 各分岐点で、選ばなかった選択肢の結末分布（N=30 程度のヘッドレス試算）を表示。Web Worker で計算し UI を止めない。
- **FR-33** シナリオ作者が書いた教訓を、条件（選択や最低体温など）に応じて表示する。
- **FR-34** 任意の分岐点から「ここからやり直す」ができる（スナップショット復元）。

### 保存・設定
- **FR-40** 自動保存（分岐点ごと＋ゲーム内 30 分ごと）。再開可能。
- **FR-41** 実行履歴（シナリオ・日時・結末・選択の要約）を一覧できる。
- **FR-42** 設定: 画質（低/中/高）、フィギュア拡大率、自動一時停止の対象、判断時間制限モード、情報モード既定値、音（初版は無音でよい）。

### シナリオ作成者向け
- **FR-50** `npm run validate` でマップ・シナリオ JSON を検証し、未定義ノード ID・未定義分岐点参照・時刻書式エラーなどを行番号相当のパスつきで報告する。
- **FR-51** `npm run mc` で方針別の結末分布を出し、シナリオの `balanceTargets` と比較して合否を表示する。
- **FR-52** 開発ビルドでは URL パラメータ `?scenario=<id>&debug=1` でデバッグパネル（World の主要値、乱数ストリーム状態、条件評価結果）を出せる。

### シナリオエディター（詳細は docs/15〜18）
- **FR-60** 地理院地図の上で範囲（2〜12.3 km 四方）を指定し、国土地理院の標高タイルから箱庭の地形を作れる。
- **FR-61** OpenStreetMap（Overpass API）から登山道・山頂・鞍部・山小屋・避難小屋・滝・登山口を取り込み、登山道グラフに変換できる。使う道を選んで確定できる。
- **FR-62** GPX ファイルを登山道・計画ルート・偽の道として取り込める。
- **FR-63** 地図上で登山道を手描き・分割・結合・編集でき、傾斜を確認できる。
- **FR-64** 登山道の属性（難度、道標、踏み外しやすさ、標準コースタイム）と、分岐の紛らわしさを編集できる。紛らわしい分岐は自動で候補を出す。
- **FR-65** 植生（森林限界と塗り直し）と電波（基地局の配置と塗り直し）を編集できる。
- **FR-66** 天候をタイムラインで編集でき、天気パターン（寒冷前線、温暖前線、南岸低気圧、冬型、夏の雷雨、霧、梅雨、台風、移動性高気圧）を差し込める。
- **FR-67** 指定した日の過去の気象（Open-Meteo 再解析）を取り込み、天候の下書きにできる。
- **FR-68** 雷雲の進路を地図上に描ける。確認地点での局地気象をタイムラインの任意時刻で表示できる。
- **FR-69** 登山者・装備（プリセットあり）・計画ルート（地図クリック）・予報・分岐点（条件ビルダー）・イベント・結末・教訓をフォームで編集できる。JSON を直接編集することもできる。
- **FR-70** 常時検証し、エラー・警告を一覧と地図上の印で示す。
- **FR-71** ヘッドレス試走（1 回・まとめて）とその結果表示、`balanceTargets` の合否判定ができる。
- **FR-72** 編集中のシナリオをプレイヤーで 3D で遊べる。
- **FR-73** バンドル（`*.hakoniwa.json`）として書き出し・読み込みできる。プロジェクトはブラウザ内（IndexedDB）に自動保存され、Undo/Redo できる。
- **FR-74** プレイヤーはバンドルをファイルから読み込める。`index.json` にバンドルを登録できる。出典をブリーフィングと画面隅に表示する。

## 2. 非機能要件

- **NFR-01 対応環境**: 最新の Chrome / Edge / Firefox / Safari（macOS）、iOS Safari 17 以降、Android Chrome。WebGL2 必須。非対応時は案内を出す。
- **NFR-02 性能**: デスクトップ（内蔵 GPU）で 60fps、ミドルレンジスマホで 30fps を「中」画質で目標。シミュレーション 1 ティックは 0.2ms 以下（登山者 3 人）。×60 速度（毎実秒 360 ティック）でも描画が 30fps を割らないこと。
- **NFR-03 起動**: 初回ロード（gzip 後 JS + マップ + シナリオ + 基本のモデル）1.5MB 以下。高画質用のアセットは後から読み込む（docs/10 §10。合計の目安 20MB 以下）。地形生成と派生レイヤー計算は 1.5 秒以内（中位スマホ）。重い計算（電波圏の見通し計算など）は Worker で行い、結果を IndexedDB ではなく `localStorage` でもなく **メモリにのみ** 保持してよい（再計算が速いなら）。
- **NFR-04 決定論**: 同一シナリオ・同一シード・同一選択列なら、ブラウザ／Node を問わず結果のレコードのハッシュが一致すること（浮動小数の演算順序を固定し、`Math.random`・時刻依存を排除）。
- **NFR-05 レイアウト**: 横幅 360px のスマホ縦画面〜デスクトップまで。スマホではパネルをボトムシートのタブにまとめる。
- **NFR-06 アクセシビリティ**: 体温などの段階は色だけでなくアイコンと文字で区別。文字は最小 12px、本文 14px 以上。主要操作はキーボード操作可（Space: 一時停止、1〜5: 速度、Tab で選択肢移動）。
- **NFR-07 表現**: 死亡・負傷の描写は抑制的に（CLAUDE.md 参照）。
- **NFR-08 国際化**: 初版は日本語のみ。UI 文字列は `src/i18n/ja.ts` に集約。
- **NFR-09 オフライン**: プレイヤーは一度読み込めば通信なしで動作（外部 CDN・Web フォント不使用。フォントはシステムフォント）。エディターは地形・登山道・過去の天気の取り込み時のみ通信し、取り込んだデータはプロジェクトに保存して再取得しない。
- **NFR-10 エディターの対象環境**: デスクトップの最新 Chrome / Edge / Safari / Firefox、幅 1024px 以上。
- **NFR-11 外部サービスへの配慮**: 同じ範囲・同じ期間の再取得をしない。タイル取得は同時 4 本まで。Overpass はエリアごとに 1 回。
