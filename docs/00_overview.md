# 00 概要

## 1. コンセプト

**山の遭難シミュレータ**（旧称: 箱庭遭難シミュレータ）は、机の上に置いたジオラマのような架空の山「箱庭岳（はこにわだけ）」を舞台に、
登山者が遭難へ向かっていく（あるいは踏みとどまる）過程を、気象の変化とともに 3D で観察する Web アプリである。

- ユーザーは **観察者**。基本は眺めているだけで時間が進み、天気が変わり、登山者が歩き、疲れ、濡れ、冷えていく。
- ときどき **分岐点（チョイスポイント）** が来る。ユーザーは登山者の立場で行動を選ぶ。
- 選択は結果を直接決めない。行動が変わり、その後の推移はシミュレーションが決める。同じ選択でも結果が変わることがある。
- 終わると **振り返り** で、体温・天気・判断のタイムラインと「もしあの時こう選んでいたら」の試算が見られる。

## 2. 体験の柱

| 柱 | 内容 |
|---|---|
| 箱庭を眺める | 山全体が手のひらサイズに見えるジオラマ表現。雲が稜線にかかり、雨が箱の中だけに降り、夜には登山者のヘッドランプだけが光る |
| 推移が見える | 「ちょっとした判断の遅れ」が数時間後に効いてくる因果を、体温グラフ・思考の吹き出し・行動ログで追える |
| 判断の重さ | 分岐点では「登山者が知っていること」と「観察者だけが知っていること」が分かれて見える（情報モードで切替） |
| 教訓が残る | 振り返りで分岐ごとの別の結末の確率を見せ、シナリオ作者が書いた解説を表示する |
| 作れる | シナリオエディターで、実在の山のエリア（国土地理院の標高）、登山道（OpenStreetMap / GPX / 手描き）、天候の推移（パターン・過去の天気）を指定してシナリオを作れる。成果物は 1 ファイルのバンドル |

## 3. 想定ユーザー

- 登山初心者〜中級者（講習の副教材、独習）
- 登山講習の講師（講習中にスクリーンで見せる、受講者に選ばせる）
- 山岳遭難の読み物（例: 架空遭難シリーズ）の読者
- シナリオ作者（JSON を書く人。講師本人を想定）

## 4. やらないこと（Non-goals）

- 実際の山行計画ツールとしての利用（実在の山を舞台にできるが、あくまで架空のシナリオの舞台として）
- 実在の遭難事故・実在の人物の再現
- マルチプレイ、アカウント、サーバー保存、ランキング
- 写真と見分けがつかない描画、人体の詳細なアニメーション（目標は「精密なジオラマ模型」。人はブロック玩具風の人形で表す。docs/10 §5）
- 医学的に正確な生理シミュレーション（較正目標に沿ったゲームモデルにとどめる）
- 初版でのパーティ分割（1人が助けを呼びに下る等）。型と仕様の枠だけ用意し、実装は拡張フェーズ

## 5. 用語

| 用語 | 意味 |
|---|---|
| 箱庭 / ジオラマ | 4,096 m 四方の地形を、側面に地層断面を見せた箱として描画したもの |
| マップ | 地形（手続き生成パラメータ、または実在の高さマップ）・登山道・小屋・電波局などを定義した JSON（`public/maps/*.json`、またはバンドル内） |
| バンドル | マップとシナリオを 1 つにまとめたファイル（`*.hakoniwa.json`）。エディターの書き出し形式 |
| シナリオエディター | `editor.html`。エリア・登山道・天候・分岐点を編集し、試走・書き出しする |
| シナリオ | 日時・パーティ・装備・気象タイムライン・分岐点・結末・教訓を定義した JSON（`public/scenarios/*.json`） |
| 分岐点（ChoicePoint） | 条件成立で発火し、ユーザーに選択肢を提示するもの |
| アクション（Action） | 選択肢が登山者に与える行動変更（例: 引き返す、ビバークする） |
| 自律バイアス | ユーザーが選ばない場合（観察のみモード・時間切れ）に登山者自身が選ぶ傾向 |
| 情報モード | 「神の視点」（全部見える）／「登山者の視点」（登山者が知り得る情報だけ） |
| ティック | シミュレーションの固定刻み（ゲーム内 10 秒） |
| 局地気象 | ある地点・標高での気温・風・降水・視程（全体の気象から地形補正して算出） |
| 判断力 J | 0〜1。経験・体温・エネルギー・疲労・不安から算出し、迷い・転倒・自律行動に効く |
| 運動能力 M | 0〜1。体温・負傷・エネルギーから算出し、速度・転倒に効く |
| 偽の道（False trail） | 廃道・獣道・作業道など、登山道に見えるが途中で消える踏み跡 |
| What-if | 振り返りで、ある分岐点から別の選択肢を選んだ場合をヘッドレスで多数回試算した結果 |
