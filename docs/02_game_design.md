# 02 ゲームデザイン

## 1. 1 回のプレイの流れ

```
タイトル → シナリオ選択 → ブリーフィング → シミュレーション ⇄ 分岐点 → 結末 → 振り返り → (やり直し / 別シナリオ)
```

1 シナリオの実時間の目安は 10〜25 分（×1〜×15 を併用）。ゲーム内では 6〜30 時間程度。

## 2. 時間

| 項目 | 値 |
|---|---|
| シミュレーション刻み | ゲーム内 10 秒（固定） |
| ×1 | ゲーム内 1 分 / 実 1 秒（6 ティック/秒） |
| ×4 / ×15 / ×60 | 24 / 90 / 360 ティック/秒 |
| 時刻表示 | `10月17日 13:42`（シナリオの開始日付から計算） |

夜間のビバーク待機などで ×60 を使う。×60 中も分岐点・設定された重要イベントで停止する。

## 3. 選択肢設計の原則（シナリオ作者向けガイドも兼ねる）

1. **選択は行動を変えるだけ**。結果（助かる／死ぬ）を直接書かない。例外は「中止する→家に帰る」のような自明な終了のみ。
2. **正解が 1 つに見えすぎない**。各選択肢にもっともらしい理由を添える（「小屋まで 40 分。止まると冷える」など）。
3. **登山者の性格を反映**。各選択肢に自律バイアス（`bias`）を設定し、登山者の経験・リスク許容度・状態で重みを変える。観察のみモードで「この人ならこうする」が再現される。
4. **推奨と危険のタグ**。各選択肢に `tags: ["recommended"]` や `["risky"]` を付ける。モンテカルロの方針と教訓の判定に使う。プレイヤーには表示しない。
5. **情報の非対称**。状況文と「登山者が把握していること」は登山者の視点で書く。真の天候推移は神の視点の UI だけが示す。
6. **汎用分岐点**。シナリオが書いていない状況（道迷いに気づいた、日没、低体温の進行、負傷、雷接近）には、エンジン組み込みの汎用分岐点が出る（`docs/09_scenario_format.md` §7）。シナリオは同じキーで上書きできる。

## 4. 情報モード

| 項目 | 神の視点 | 登山者の視点 |
|---|---|---|
| 登山者の位置 | 真の位置 | 道迷いに気づくまでは「計画ルート上の推定位置」。気づいた後は GPS で確認するまで「不明」表示 |
| 気象パネル | 局地気象の数値 | 体感の言葉（「冷たい雨」「強い風」「霧で 50m 先が見えない」） |
| 体温など | 数値＋バー | 段階の言葉のみ（「震えが止まらない」） |
| 先の天気 | タイムラインに今後の推移を薄く表示 | 出発前の予報のみ（シナリオの `forecast`） |
| オーバーレイ | すべて | 計画ルート・登山道のみ |

既定は「神の視点」。振り返りの What-if は情報モードによらず同じ。

## 5. 結末

エンジンが自動判定する結末の種類（`EndingKind`）。シナリオは `endings` で文言と追加条件を上書き・細分化できる。

| kind | 判定 | トーン |
|---|---|---|
| `SAFE_RETURN` | 全員が下山口ノードに到達 | 良 |
| `SAFE_SHELTER` | 全員が営業小屋/避難小屋で制限時間を迎えた、または翌朝以降に安全に下山 | 良 |
| `ABORTED` | 出発前・序盤に中止して終了 | 良（教訓的） |
| `SELF_RESCUE` | ビバークを経て自力下山 | 中 |
| `RESCUED` | 救助隊/ヘリに収容（収容時の体温 ≥ 32℃） | 中 |
| `RESCUED_CRITICAL` | 収容時に重度低体温症（< 32℃）または重傷 | 悪 |
| `MISSING` | 制限時間時点で生存しているが未発見・未下山 | 悪 |
| `FATAL` | 1人以上死亡（原因: 低体温症 / 滑落 / 落雷 / 外傷） | 悪 |

複数人パーティでは最も悪い結末を採用し、個人ごとの結果も表示する。

## 6. 振り返り（概要。詳細は `docs/12_debrief_replay.md`）

- 体温・エネルギーと気象の時系列グラフに、分岐点（◆）と主要イベント（●）を重ねる。
- 各分岐点について「選んだ選択肢」「他の選択肢を選んだ場合の結末分布（What-if）」を棒グラフで表示。
- シナリオの教訓（`lessons`）を条件に応じて表示。
- 「この分岐からやり直す」ボタン。

## 7. 表現のトーン

- 思考の吹き出しは、本人の主観（正常性バイアス、焦り、楽観）を含めて書く。観察者が「それは危ない」と感じる距離感を作る。
- セリフ（声に出した言葉）は角丸・尻尾付きの吹き出しで出し、思考とは見た目で区別する（docs/11 §8）。体温が下がるとろれつが回らなくなり、やがて話さなくなる（docs/07 §7.4）。周りの人の声かけと、それに応えなくなることで、仲間の異変に観察者が気づけるようにする。
- イベントログは客観的な短文（「13:42 雨が強まった（8mm/h）」「14:10 雨具を着用」）。
- 死亡の表示は「登山者は動かなくなった」程度にとどめ、結末画面で原因を事実として記す。

## 8. 観察を楽しくする仕掛け

- **注目ピン**: 重要イベント発生地点に一時的なピンを立て、俯瞰カメラでも気づけるようにする。
- **自動カメラ（任意設定）**: 重要イベントのたびに追従カメラへ寄り、落ち着いたら俯瞰に戻る。
- **箱の外の時計**: ジオラマの台座に真鍮プレート風の時刻表示（3D テキストではなく Canvas テクスチャで十分）。
- **登山者のスマホ画面**（拡張フェーズ）: 電池残量、電波、地図アプリの現在地表示を小窓で見せる。
