# 11 UI（`src/ui/`）

基本は DOM + CSS（CSS 変数でテーマ）と Canvas2D。UI フレームワーク・チャートライブラリなどは、CLAUDE.md「依存の追加」に従って確認のうえ使ってよい。フォントはシステムフォント。
UI は `World` を 4Hz で読み取り表示を更新する。ユーザー操作は `app/session.ts` の関数を呼ぶ。

## 1. 画面一覧

| 画面 | 内容 |
|---|---|
| `TitleScreen` | 題名、続きから（自動保存があれば）、はじめる、履歴、設定 |

## 5. EndingScreen

## 8. 吹き出し（セリフと思考）

### 8.1 セリフの吹き出し（基本形）

キャラクターにセリフがあるとき、その人の頭上に **角丸・尻尾付きの吹き出し** を出す。

```
        ガイドB                       ← 話し手の名前（10px、話し手の色）
   ╭──────────────────╮
   │ しゃがんで！        │            ← 本文（14px、最大 2 行、超えたら省略）
   ╰────╮ ╭──────────╯
         ╲│                          ← 尻尾（先端が頭の真上 8px を指す）
          ●  ← フィギュア
```

| 項目 | 値 |
|---|---|
| 形 | 角丸長方形。角の半径 12px（2 行以上は 14px） |
| 尻尾 | 二等辺三角形、根元幅 14px・長さ 10px。先端は常に話し手の頭の投影位置を指す。吹き出しを左右にずらしても、尻尾の根元は吹き出しの下辺上でずれ、先端は動かない（根元は角丸から 12px 以上内側に制限） |
| 余白・幅 | 内側の余白 6px 10px。最大幅 220px（スマホは 64vw）。2 行を超える文は「…」で省略し、ログに全文 |
| 色 | 背景 白（ダークテーマでは #1e1e1e）、文字 #222、枠 1.5px 話し手の色。影 0 2px 6px rgba(0,0,0,.25) |
| 描画方式 | DOM（`position:absolute` の div）を 3D キャンバスの上に重ねる。尻尾は `::after` の CSS 三角形ではなく、枠線を連続させるため **SVG の path で吹き出しと尻尾を一体で描く**（`bubblePath(w, h, r, tailX, tailLen)` を自作） |
| 出現・消滅 | 出現: 120ms で scale 0.85→1 と不透明度 0→1（尻尾の先端を変形の原点にする）。消滅: 200ms フェード |
| 表示時間 | 実時間で `2.0 + 0.09 × 文字数` 秒（最短 2.5 秒、最長 7 秒）。一時停止中は消さない。×15 以上では優先度 20 未満を表示しない |
| 話しかけ | `to` があるとき、名前の行を「ガイドB → 女性客H」とする |

### 8.2 種類（`tone` と思考）

| 種類 | 見た目 |
|---|---|
| `normal` | 8.1 の基本形 |
| `shout` 叫ぶ | 枠 2.5px、本文太字 15px、出現時に 1 回だけ 1.08 倍まで弾む。角丸は同じ（トゲ形にはしない） |
| `whisper` 小声 | 枠を破線、本文 12px・灰色 #666、不透明度 0.85 |
| `sound` 擬音・笛 | 枠なし、本文のみ太字（例「ピーッ」）、尻尾なし |
| 思考（docs/07 §6） | セリフと区別するため、**角丸だが尻尾の代わりに小さな丸 2 つ**（直径 6px と 4px）を頭に向けて並べる。背景 #f4f4f4、文字は斜体 #555 |
| 構音障害（docs/07 §7.4） | 形は通常どおり。本文を小刻みに揺らす（振幅 1px、周期 120ms）。`prefers-reduced-motion` では揺らさず、名前の横に「（ろれつが回らない）」を表示 |
| 史実シナリオの記録 | 本文の下に小さく「記録」バッジ（青系）。文言が残っていない場合は内容を括弧書きで灰色 |
| 史実シナリオの架空 | 本文の先頭に **※**（本文と同じ大きさ・色）。本文の下に小さく「架空」バッジ（灰色系、文字 11px）。形・色・大きさは通常と同じ（※とバッジで区別し、読みにくくしない） |

同じ人にセリフと思考が同時に来たら、セリフを優先し、思考は捨てる。

### 8.3 位置の追従

- 位置は毎フレーム更新する（UI の 4Hz 更新とは別）。頭の位置 = フィギュアの位置 + 身長 × `figureScale`。`Vector3.project` で画面座標へ。
- 吹き出しの下端は頭の投影位置の 18px 上（尻尾 10px + 余白 8px）。
- カメラの後ろにある（`z > 1`）ときは表示しない。
- 地形に隠れているか 250ms ごとに判定（頭→カメラの線分を高さマップで 32 点サンプル）。隠れていたら不透明度 0.5 にして名前の横に小さな「⛰」。
- 登山者視点カメラでは、視点となっている本人のセリフは画面下中央の **字幕**（角丸の帯、尻尾なし）で出す。

### 8.4 重なりの回避

1. 表示中の吹き出しを、頭の投影位置の y が大きい（手前・下）順に並べる。
2. 順に置き、既に置いた吹き出しと 4px 以上重なるなら上へずらす（最大 3 段）。
3. ずらした分だけ尻尾を伸ばす（最大 40px。超えたら優先度の低い方を待ち行列に戻す）。尻尾は先端（頭）を固定し、根元が吹き出しに付いたまま伸びる。
4. 左右は画面端から 8px 内側に収める（尻尾の根元を動かして先端を保つ）。

### 8.5 画面外

話し手が画面外にいるとき、`shout` と、選択中の登山者・重要イベントに結び付くセリフだけを、画面の縁に寄せて表示する。尻尾は話し手の方向を指す矢印形に変え、名前を必ず表示する。クリックするとその登山者へカメラを向ける。

### 8.6 表示数と大人数

- 同時に表示するのは最大 4 つ（スマホ 2 つ）。優先度: シナリオの `say`（30）> 選択中の登山者 > `shout` > テンプレート（20）> 組み込み（10）。あふれた分は待ち行列（最大 6、5 秒で破棄）。
- 大人数（docs/07 §1.4）では、追従カメラの対象から半径 200 m 以内の登山者のセリフを優先する。

### 8.7 ログ・アクセシビリティ

- すべてのセリフはイベントログに `13:42 ガイドB「しゃがんで！」` の形で残す（変形前の原文。構音障害は注記）。史実シナリオでは docs/07 §7.5 の形式（※と「架空のセリフ」／「記録」）。
- 吹き出しとは別に、画面外の `aria-live="polite"` 領域にも同じ文を流す（読み上げ用）。
- 設定: 「セリフの吹き出し」ON/OFF、「思考の吹き出し」ON/OFF、「史実シナリオで架空のセリフを出す」ON/OFF、文字サイズ（小・中・大）。
- 史実シナリオでは思考の吹き出しも架空であるため、同じく先頭に※を付け、「架空」バッジを出す。
