## 動かし方（P19 以降）

1. エディターでスケルトンマップを読み込む（docs/16 §8）。
2. 地図上で範囲を置き、国土地理院の標高と OpenStreetMap の登山道を取り込む。
3. 地名で自動結合されたノードを確認し、ずれていれば地図上で直す。
4. 電波の塗り（北沼付近は圏外、南沼・前トム平付近は通話可）と森林限界を確認する。
5. バンドルとして書き出し、`public/scenarios/historical/` に置いて `index.json` に `bundle` で登録する。

## 扱いの方針

- 人物は調査報告書の記号で表記し、実名は使わない。
- 年齢・性別・役割・経過は記録、体重・体力・装備細部・体温は推定（`estimated` を参照）。
- 結末画面ではシミュレーションの結果と実際の記録を分けて表示する。
- 出典: トムラウシ山遭難事故調査特別委員会『トムラウシ山遭難事故調査報告書』日本山岳ガイド協会, 2010 ／ 消防庁「北海道トムラウシ山における山岳遭難救助事故について（最終報）」2009
